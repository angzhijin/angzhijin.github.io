服务器基础搭建

发表于2021-07-17|更新于2022-04-22|服务器
|字数总计:2.8k|阅读时长:11分钟|阅读量:

服务器三大件（JDK，Tomcat，MySQL）以及本人项目需求中的其他软件（Nginx，PostgreSQL等）的安装与配置

#服务器基础

本人的服务器基于腾讯云轻量级应用服务器进行搭建，相比于云服务CVM，在一些功能上有了限制，不过对于本菜狗来说完全够用了

服务器系统为Ubuntu 18.04 1 LTS。

  1. 远程连接

    1. ssh

      ssh {用户名}@{服务器ip地址}

      如系统重置，因密钥改变，需要删除 C:\Users\用户/.ssh/known_hosts 中对应的密钥重新建立连接

    2. winSCP （下载链接）

  2. 安装工具

    1. apt-get

      apt-get是一款适用于Unix和Linux系统的应用程序管理器。

      • 系统安装软件一般在 /usr/share，可执行的文件在 /usr/bin，配置文件可能安装到了/etc下等。

      • 文档一般在 /usr/share

      • 可执行文件 /usr/bin 或 /usr/sbin

      • 配置文件 /etc

      • lib文件 /usr/lib

    2. apt

      apt流行于Ubuntu 16.04版本后，与apt-get的使用在大部分情况下基本相同，官方也鼓励使用apt

    查询已安装的包dpkg -l|grep '^ii'

    或安装sudo apt-get install aptitude，运行sudo aptitude进行查看

    • 列出所有可更新的软件清单：sudo apt update
    • 升级软件包：sudo apt upgrede
    • 查找软件包：sudo apt search <keyword>
    • 列出可更新的软件包及版本信息：apt list --upgradeable
    • 列出所有已安装的软件包：apt list --installed
    • 列出所有已安装的包的版本信息：apt list --all-versions
    • 安装软件包：sudo apt install <package_name1> <package_name2>...
    • 删除软件包：apt remove <package_name>
    • 自动清理不再使用的软件包：sudo apt autoremove

  3. 防火墙（这里直接用腾讯云终端自带的即可，再使用相当于墙中墙）

#JDK

可以安装Oracle，也可以安装OpenJDK。以下均以Oracle为例。

#安装包安装

  1. 下载jdk并上传到服务器（下载链接）

  2. 解压 tar -zxvf jdk-8u271-linux-x64.tar.gz

  3. 移到指定目录 sudo mv jdk1.8.0_271 /usr/lib/jdk1.8

  4. 设置环境变量 sudo vim /etc/profile （如果是zsh则为~/.zshrc）

  5. 使配置环境生效并检查 source /etc/profile ;

  6. 查看版本号 java -version

#yum安装

  1. 检查是否已安装javayum -qa | grep java
  2. 查找可用包yum list | grep java-1.8.0-openjdk
  3. 安装yum -y install java-1.8.0-openjdk*
  4. 查看版本号java -version

#更新

删除原安装目录，解压新版本换到同一目录下即可，还可以省的改配置

#Tomcat

#安装包安装

  1. 下载(下载链接)

  2. 解压 tar -zxvf apache-tomcat-8.5.61.tar.gz

  3. 移到指定目录 sudo mv apache-tomcat-8.5.61 /opt/tomcat8

  4. 配置环境变量 sudo vim /opt/tomcat8/bin/startup.sh ;

    ​ sudo vim /opt/tomcat8/bin/shutdown.sh

  1. 启动tomcat服务器/opt/tomcat/bin/startup.sh
  2. 浏览器输入 {IP地址}:8080
  3. 关闭tomcat /opt/tomcat/bin/shutdown.sh

要实现tomcat的可视化管理，需要在/conf/tomcat-user.xml中根据模板添加用户manager-gui

另外，默认是只有同一机子上才可以访问，其他的均为403，需要去context.xml中配置访问IP

#自启动设置

  1. 修改tomcat8下的/bin/setclasspath.sh文件

  2. 在/etc/systemd/system/目录下添加tomcat8.service文件

    注意要修改为自己的路径，如果忘记改了，之后补上，需要执行systemctl daemon-reload来重新载入单元模块

  3. 添加可执行权限 sudo chmod +x tomcat8.service

  4. 此时可以通过systemctl命令来控制tomcat

    • 启动服务 sudo systemctl start tomcat8
    • 查看状态 sudo systemctl status tomcat8
    • 停止服务 sudo systemctl stop tomcat8

  5. 设置开机自启

    出现Created symlink /etc/systemd/system/multi-user.target.wants/tomcat8.service → /etc/systemd/system/tomcat8.service.说明成功

#MySQL

#apt-get安装

  1. 更新apt-get apt-get upgrade

  2. 安装 mysql-client-core-5.7 apt-get install MySQL-client-core-5.7

  3. 安装mysql-client-5.7 apt-get install mysql-client-5.7

  4. 安装 mysql-server-5.7 apt-get install mysql-server-5.7

  5. 检查mysql是否启动 service mysql restart

    ubuntu下，ERROR 1045 (28000): Access denied for user ‘root’@‘localhost’ (using password: YES)的解决方案

    1. 命令行输入：sudo vi /etc/mysql/mysql.conf.d/mysqld.cnf

      在[mysqld]后面任意一行添加skip-grant-tables用来跳过密码验证的过程保存文档并退出

    2. 接下来我们需要重启MySQL：/etc/init.d/mysql restart

      显示如下：

      […] Restarting mysql (via systemctl): mysql.serviceFailed to add /run/systemd/ask-password to directory watch: No space left on device

      . ok

    3. 重启之后输入mysql即可进入mysql。

  6. 修改密码（root初始密码为0000）

    1. 忘记密码时，使用cat命令查看默认密码 sudo cat /etc/mysql/debian.cnf

    2. 使用默认密码登录

    3. 修改密码

    4. 重启服务 /etc/init.d/mysql restart

    5. 退出重新登录 mysql -u root -p

  7. 修改远程登录

    1. 进入超级用户，修改 /etc/mysql/my.cnf ，添加

      也可能是引入 /etc/mysql/mysql.conf.d/mysqld.cnf 配置 ，过去注释掉 bind-address

    2. 赋予用户远程连接权限，并刷新

    3. 重启 /etc/init.d/mysql restart

  1. MySQL要支持中文字符

    3. 重启mysql，查看STATUS
