Zookeeper初探

发表于2022-06-24更新于2026-07-18阅读次数

Zookeeper 是一个分布式的、开源的程序协调服务，是 hadoop 项目下的一个子项目。他提供的主要功 能包括：配置管理、名字服务、分布式锁、集群管理。

  • Apache ZooKeeper

  5. 启动Server

    此时可能会显示：JAVA_HOME is not set and java could not be found in PATH.。具体原因找了好一会也没找到（明明配置了）。

    解决方法：

    zookeeper 启动时会执行两个文件zkServer.sh和zkEnv.sh，在zkEnv.sh中会检测PATH中是否有JAVA_HOME，但读不到。所以就手动在这段代码前对JAVA_HOME进行赋值。

  6. 查看server状态

    可能会显示Error contacting service. It is probably not running.。

    去logs/zookeeper-root-server-LAPTOP-37EKRTG8.out中查看，能看到Problem starting AdminServer on address 0.0.0.0, port 8080 and command URL /commands

    原因之一是zookeeper启动时默认会将AdminService服务启动，这个服务默认是8080端口，导致冲突，这就要在配置文件中将其配置为其他端口admin.serverPort=9090
