发表于2023-01-31更新于2026-07-18阅读次数

最近又接到俺哥的需求了，需要根据Excel中的经纬度在GoogleMap上打标记，巧的是俺哥来问的时候我刚好在调我的openlayers自制地图项目。仔细一想，这一类功能各大地图商似乎都有自己的接口，这个似乎不难，写个html应该就能实现了吧，就试试呗。

根据需求，先是设计了以下格式的表格

lat lng
-25.363 131.044
-20.363 131.044

也是第一次发现，叫着经纬度，但常用的经纬度格式实际是(纬度latitude, 经度longitude)

顺便记一下首都北京的经纬度lat: 39.90, lng: 116.40

#上传按钮DOM&事件

地图上控件怎么加？由于对html并不熟悉，唯一会的也是套着框架写，单让我写html以及DOM绑定那就超纲了。所幸，在官方的Demo中找到了类似的地图内控件的添加，在此基础上稍作了修改

  • Demo：地理定位：在地图上显示用户位置或设备位置 | Maps JavaScript API | Google Developers

咋读？实际上File对象可以根据空间的事件中获取，所以要定义<input type="file"></input>的响应事件。为了便于操作，我定义的是change事件，通过传入事件e来获取文件对象e.target.files

大致来说，转换关系为：File Object -> WorkBook Object -> Sheet Object -> JSON

#结语

也仅仅是一个小需求吧，前前后后总共花的事件也就俩小时，不知道算啥水平。实际使用中因为涉及到上百个标记点，标记的速度也挺慢，我这边也没给实测数据，也懒得造数据做压测，就先让凑合着用吧。

但确实感受到了多学的好处，照着Demo很容易懂也很容易改，但一到造轮子，自己就不知道落了多少条街，也就只是个API工程师罢了，未来堪忧啊
