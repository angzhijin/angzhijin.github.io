发表于2022-07-02更新于2026-07-18阅读次数

随着使用原来越深入，光MySQL这块就不再局限于安装部署的内容的，干脆就专门为MySQL来水一篇。

#安装

建议安装5.7，使用较多

#Windows

Windows下安装也没啥难度，基本都是可视化界面，也没啥好说的，用的系统多了以后还是觉得UNIX类的操作系统便于开发环境。

  1. 下载地址：MySQL :: Download MySQL Community Server (Archived Versions)
  2. 配置文件：C:\ProgramData\MySQL\MySQL Server 5.7\my.ini

#Linux

ubuntu20.04默认源的mysql版本为5.7，需要修改源或源码安装（在WSL 上未成功，最后还是将WSL改为了Ubuntu18.04）

但Linux还是推荐直接用apt/apt-get来

  1. 更新apt-get apt-get update

  2. 安装 mysql-client-core-5.7 apt-get install MySQL-client-core-5.7

  3. 安装mysql-client-5.7 apt-get install mysql-client-5.7

  4. 安装 mysql-server-5.7 apt-get install mysql-server-5.7

  5. 检查mysql是否启动 service mysql restart 或 systemctl status mysql

    ubuntu下，ERROR 1045 (28000): Access denied for user ‘root’@‘localhost’ (using password: YES)的解决方案

    1. 命令行输入：sudo vi /etc/mysql/mysql.conf.d/mysqld.cnf

      在[mysqld]后面任意一行添加skip-grant-tables用来跳过密码验证的过程保存文档并退出

    2. 接下来我们需要重启MySQL：/etc/init.d/mysql restart

    3. 重启之后输入mysql即可进入mysql。

#注意

  1. 新建数据库时编码规则别用utf8，这是早期mysql使用的不完整的UTF-8，需要使用utf8mb4

#密码修改

  1. 忘记密码时，使用cat命令查看默认密码 sudo cat /etc/mysql/debian.cnf，使用默认密码登录（也可以直接sudo mysql以超级管理员进入）

  2. 修改密码

    mysql 5.7.9 以后废弃了password字段和password()函数，authentication_string字段表示用户名密码，只能是是mysql加密后的41位字符串密码。

    mysql 8.0 后修改密码有了变化

  3. 重启服务 /etc/init.d/mysql restart

  4. 退出重新登录 mysql -u root -p

#Expression #1 of SELECT list is not in GROUP BY clause and contains nonaggregated column

原因：

使用的GROUP BY 语句违背了sql_mode=only_full_group_by。MySQL 5.7之后默认的模式是ONLY_FULL_GROUP_BY（拒绝选择列表、HAVING 条件或 ORDER BY 列表引用非聚合列的查询）。

解决方法：

  1. 查询mysql的sql_mode
  2. 重新设置sql_mode，去掉ONLY_FULL_GROUP_BY
  3. 退出重进

以上方法在mysql重启后会被重置，保证持久化需要在配置文件/etc/mysql/mysql.conf.d/mysqld.cnf中添加到[mysqld]最后
