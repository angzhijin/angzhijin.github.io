GeoServer图层发布

发表于2022-04-19更新于2026-07-18阅读次数

geoserver配合postgresql+postGIS发布地图可真是太舒服了！

2022/6/25：补充一个宝藏教程【Geoserver】你猜猜我做了多少关于Geoserver的内容~_哔哩哔哩_bilibili

#建立数据连接

  1. 登陆geoserver

  2. 在工作区中为自己的项目单独建立一个工作区（命名空间也必填，随便填下）

  3. 在数据存储中选择添加新的数据存储

  4. 选择PostGIS（还有shapefile等数据源选项）

  5. 选择工作区，为其命名，并输入数据库host、port、database、user、passwd等，保存即可

#发布图层

  1. 进入图层项，选择添加新的资源

  2. 选择自己的工作区

  3. 选好后会自动连接至数据库，列出数据库中的所有表

    包括不含空间信息的表也会列出，如业务表

    已发布的会显示勾，操作也会变为再次发布

  4. 选择自己想要发布的图层，点击发布进行配置。主要配置内容为图层命名、坐标参考系统SRS、边框等

    SRS由于本人没有经过系统学习不是很懂，也算是运气好，看眼缘选择的2406刚好适合自己项目所需

    边框可以通过点击从数据中计算, compute from native bounds自动获取

  5. 选择保存/Apply

#图层预览

  1. 对于图层较多时可以使用搜索

  2. 预览的格式很多，除了显示的Openlayers / GML / KML，在Select one中，还有 PNG / JPG / GeoJSON等多种格式 。

#图层组

以上是单个图层的情况，多个图层同样可以。

  1. 进入图层组，选择添加新图层组

  2. 选择工作区（不选则使用所有工作区）

  3. 在图层中添加多个图层

    • 位置在上面的先渲染，即位置越上面的，图层位于最下面
    • 风格为Openlayer显示的风格，使用css配置，在样式中进行管理

  4. 点击生成边界，自动得到边界与SRS

  5. 点击保存/Apply

  6. 回到图层预览进行查看

#样式

样式的处理难度比较大，一般是按照形状（Point、Line、Polygon等）默认生成，或是从已有样式导入进行修改

最后展示一下自己的半成品吧

---------2022/10/15

终于想着来补一补了，其实这样式难度也不大，用QGIS就很方便，另外还有一个 SLD Edit 也可以，不过并没有去试过。

  • 参考Geoserver06-快速地图配置_哔哩哔哩_bilibili

  1. 图层样式中编辑“符号化”、“标注”等

  2. 导出为SLD，添加到geoserver样式中

  3. geoserver中“添加样式”，将导出的文件内容全部复制到编辑器中

    QGIS插件推荐

    • Bulk vector export：图层导出
    • SLD4raster：样式导出为文件或上传到geoserver
    • Clip Multiple Layers：图层裁剪

    不过呢，由于QGIS在图层样式提供的功能很多，有些比较复杂的就不太容易在geoserver中实现，特别是带表达式的样式，这里挂一下我磨了好久的图呗～（虽说还是挺丑）
