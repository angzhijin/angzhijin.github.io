Java之JSON工具类

发表于2021-12-22更新于2026-07-18阅读次数

JSON(JavaScript Object Notation) 是一种轻量级的基于文本的数据交换格式，是很理想的数据交换语言。但在Java中没有内置 JSON 的解析，所以需要调用第三方库

目前比较常用的 JSON 库有：

  • Gson：谷歌开发的 JSON 库
  • FastJson：阿里巴巴开发的JSON库
  • jackson：社区相对活跃，更新较快

#Gson

  • Gson GitHub主页：google/gson: A Java serialization/deserialization library to convert Java Objects into JSON and back

  • User Guide：gson/UserGuide.md at master · google/gson

#Gson与注解更配哦

#@Expose

采用@Expose对对象属性添加注解，同时Gson对象配置为private static Gson gson = new GsonBuilder().excludeFieldsWithoutExposeAnnotation().create();，可以排除不想转换进json的属性。

#@SerializedName("value")

修改属性序列化后的名字为value

#@Since(1.0)

配合Gson的setVersion()配置，允许某一版本之后的gson对象生成相应字段

#@Until(2.0)

配合Gson的setVersion()配置，允许某一版本之前的gson对象生成相应字段

#注解

#@JSONField

作用于Javebean的field和getter/setter

但仅依赖于getter/setter进行

  • name：JSON中的名字

  • serialize/deserialize：是否序列化/反序列化

  • format：用于Date的格式化

    eg. @JSONField(name="update_time", formate="yyyy-MM-dd HH:mm:ss")

  • ordinal - 字段顺序
