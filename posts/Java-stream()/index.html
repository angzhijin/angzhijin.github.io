Java之stream()

发表于2021-08-11更新于2026-07-18阅读次数

stream是Java8中用以处理集合的关键抽象概念，与Lambda配合使用可以实现对集合的各种操作，可以执行非常复杂的查询，过滤映射数据等操作。

“Stream流”其实是一个集合元素的函数模型，它并不是集合，也不是数据结构，其本身并不存储任何元素（或其地址值）。

#特点

  1. stream不是一个数据结构，不存储数据，而是按照特定的规则对数据进行计算，一般会输出结果。
  2. stream不会改变数据源，通常情况下会产生一个新的集合或一个值。
  3. stream具有延迟执行特性，中间处理过程中只是对操作进行了记录，并不会立即执行，只有调用终端操作时，中间操作才会执行。
  4. 为lambda表达式设计

#操作类型

#中间操作（Intermediate ）

Stream可以进行多次中间操作，如filter、sort。

该操作是惰性化的

  • 无状态：指元素的受理不受之前元素的影响
    • unordered()
    • filter()
    • map(), mapToInt(), mapToLong()，mapToDouble()
    • flatMap(), flatMapToInt(),flatMapToLong(), flatMapToDouble()
    • peek()
  • 有状态：指该操作只有拿到所有数据之后才能继续下去
    • distinct()
    • sort(), sorted()
    • limit(), skip()

#结束操作（Terminal）

一个stream只有一个结束操作，

  • 非短路操作：指必须处理所有元素才能得到最终结果
    • forEach(), forEachOrdered()
    • toArray()
    • reduce()
    • collect()
    • max(), min(), count()
  • 短路操作：指遇到某些符合条件的元素就可以得到最终结果，如 A||B
    • anyMatch(), allMatch(), noneMatch()
    • findFirst(), findAny()

#映射 map/flatMap

将流中元素映射到另一个流中

map：接收一个函数为参数，该函数会被应用到每个元素上，并将其映射成一个新的元素。

flatMap：接收一个函数作为参数，将流中的每个值都换成另一个流，然后把所有流连接成一个流。

#统计count/averaging

Collectors提供了一系列用于数据统计的静态方法：

  • 计数：count
  • 平均值：averagingInt, averagingLong, averagingDouble
  • 最值：maxBy, minBy
  • 求和：summingInt , summingLong, summingDouble
  • 统计以上所有方法：summarizingInt, summarizingLong, summarizingDouble

#去重distinct

distinct() 使用 hashCode() 和 equals() 方法来获取不同的元素。

对于自定义Object类，可以重写hashCode() 和 equals() 方法达到去重的目的。

distinct()不提供按照属性对对象列表进行去重的直接实现，可以自定义方法实现

以上方法可以被filter()接受为参数，但存在序列化的性能消耗，同时不会打乱原有顺序。
