Mac终端个性化

发表于2023-04-14更新于2026-07-18阅读次数

前段时间看了实验室大牛熟练运用自己的linux，全靠终端完成。有点向往，今天就摸鱼试着改改自己Mac终端。

原本只是想把Terminal.app的样式改改（默认的 Pro 主题看着也还好），然后搜着搜着发现大部分的操作都是采用iTerm + zsh。

#iTerm

看了下，挺馋iTerm的状态条的～

其他方面说是比Terminal.app更多的配置内容

  • 官网：https://iterm2.com/
  • 下载链接（最新版）：https://iterm2.com/downloads/stable/latest
  • 说明文档：https://iterm2.com/documentation.html

下载并解压后得到iTerm.app，复制或拖拽到Application中，就可以在 LanuchPad 中看到并可以启动

#配色方案

Preferences > Profiles > Colors，通过Color Presets切换不同的主题。

可以从网上下载其他iTerm色彩主题导入配置。

#时间戳

  1. View -> Show Timestamp在命令行右侧显示时间，但要注意会遮挡右侧界面
  2. Profiles -> Session -> Show timestamp:Always

#状态条

在Preferences > Profiles > Session 下选中Status bar enabled，进入Configure Status Bar就可以拖动想要配置的状态条。

其中包括了处理器和内训利用率，网络吞吐量、搜索框、时间、当前主机/用户/任务名称、git状态等等。

#字体

Preferences -> Profile -> Test -> Font -> Change Font -> select 'Use a differentfont font for non-ASCII test'(比如中文) -> Change Font

  • Meslo

#Oh My Zsh

  • 官网：https://ohmyz.sh/
  • GitHub：https://github.com/ohmyzsh/ohmyzsh/

Oh-My-Zsh 是建立在zsh上、用户社区驱动的开源管理配置框架，综合了众多功能插件和配置主题，提供优选的初始化设置。

#安装

需求：

  • Unix-like OS
  • Zsh
  • curl / wget
  • git

#主题

.zshrc中配置ZSH_THEME=""

  • 内置Themes · ohmyzsh/ohmyzsh Wiki，默认robbyrussell

  • Powerlevel10k：灵活，高速，开箱即用（还是得看网）

#插件

.zshrc中配置plugins={}

  • zsh-autosuggestions

  • zsh-syntax-highlighting（需配置在plugins最后一项）

#参考
