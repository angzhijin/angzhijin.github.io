初探Redis

发表于2022-06-21|更新于2022-10-23|数据库
|字数总计:1.6k|阅读时长:6分钟|阅读量:

当初刷面经时候就遇到过n次redis，做项目时师兄也说像高并发应该用redis，当时也就是简单看了看，看了看尚硅谷的redis教程，感觉挺老的，也就没怎么看，因为听师兄们说redis实习面试时候说不会也没关系（/doge）。

到现在开始实习了，第一天就是要求装MySQL和Redis，并且为了安全起见，不使用默认端口，不适用弱密码。于是乎，开始了我的redis学习。

  • Redis：是一种基于简直对键值对的NoSQL数据库。

  • 特点：

    1. 支持多种数据结构（字符串、哈希、列表、集合、有序集合、位图、HyperLogLog、地理信息等）
    2. 读写性能出色
      1. 数据完全基于内存操作
      2. 执行命令使用单线程，避免线程切换和竞争产生的消耗（6.0后引入的多线程主要用于处理IO读写和协议解析）
      3. 基于非阻塞的IO多路复用机制
      4. C语言属县，基于常用的数据结构，redis做出大量优化
    3. 持久化
      1. 快照RDB
      2. 日志AOF
    4. 高可用
      1. 主从复制（一主一从、一主多从、树状主从）
      2. 哨兵（监控、故障转移、配置提供、通知）
      3. 集群
    5. 键过期、发布订阅、事务、流水线、Lua脚本等功能

  • 应用场景：缓存、计数器、排行榜、社交网络、消息队列、分布式锁

#APT

  1. 添加源并安装

  2. 启动

  3. 连接

    语法：redis-cli

    eg. redis-cli -h 127.0.0.1 -p 6379 -a 123456 使用密码123456连接到127.0.0.1:6379提供的redis服务器

  4. 配置

    • protected-mode：yes时且默认用户没有密码时，服务器只接受本地连接（IPv4：127.0.0.1，IPv6：::1）
    • requirepass：在进入cli后 执行config set requirepass foobared，退出后再次进入需要使用-a 参数连接或者是连接后执行auth foobared

#使用

#连接命令

  • redis-cli -h <host> -p <port> -a <password>

  • AUTH password：密码验证

  • ECHO message：打印字符串

  • PING：查看服务是否运行

  • QUIT：关闭当前连接

  • SELECT index：切换服务器

#服务器命令

Redis 服务器_redis教程

  • INFO [section]：获取redis服务器的各种信息和统计数值

#配置命令

配置文件位于安装目录下的redis.conf

可以通过CONFIG命令查看或设置配置项

  • CONFIG GET [CONFIG_SETTING_NAME]：查看配置项

  • CONFIG SET CONFIG_SETTING_NAME NEW_CONFIG_VALUE：设置配置项

#数据结构

类型 简介 特性 场景
字符串String 二进制安全 可包含任何数据，包括jpg图片或序列化对象 缓存、计数、共享Session、限速
哈希表Hash 键值对集合 适合存储对象 存储、读取、修改用户属性
列表List 链表（双向链表） 增删快 1. 最新消息排行 2. 消息队列
集合Set 元素不重复 添加、删除、查找的复杂度都是O(1) 提供了交集、并集、差集等操作 1. 共同好友 2. 统计访问网站的所有独立IP 3. 好友推荐，根据tag求交集
有序集合zset Set的基础上增加权重参数score，元素按score有序排列 天然排序 1. 排行榜 2. 带权重的消息队列
HyperLogLog 用于基数统计

操作命令见Redis命令 | 是藏不是藏 (zang.gold)

#事务

  1. 开始事务MULTI
  2. 命令入队（FIFO先进先出）
  3. 执行事务EXEC
  • DISCARD：取消事务，放弃执行事务块内的所有命令
  • WATCH：监听指定地的键
  1. 不满足原子性，不支持回滚（roll back）
  2. 不满足持久性
  3. Redis的事务每条命令都会与服务器进行交互，比较浪费资源
  4. 利用Lua脚本解决：一个Lua脚本可以视作一条命令执行，保证了操作不会被其他指令打扰（Lua脚本执行出错后会退出但之前执行的不会被撤销，也还是不满足原子性）

#脚本

执行脚本的常用命令为 EVAL

常用命令

  • 执行Lua脚本： EVAL script numkeys key [key ...] arg [arg ...]
  • 执行（缓存好的）Lua脚本：EVALSHA sha1 numkeys key [key ...] arg [arg ...]
  • 将脚本Script添加到脚本缓存但不立即执行：SCRIPT LOAD script
  • 查看指定的脚本是否已被保存在缓存中：SCRIPT EXIST script [script ...]
  • 从脚本缓存中移除所有脚本：SCRIPT FLUSH
  • 杀死当前在运行的Lua脚本：SCRIPT KILL
