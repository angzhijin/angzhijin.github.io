#一些名词

名词 含义
cellar 安装后的目录
keg 具体某个包的安装目录，为cellar的子目录
bottle 预先编译好的包
tap 下载源
cask 安装macOS native 应用的扩展

#使用

  • brew环境检查 brew doctor

  • 搜索 brew search [keyword]

  • 安装 brew install nginx

  • 卸载 brew uninstall nginx

  • 卸载软件及依赖 brew rmtree nginx

  • 查看信息 brew info nginx

  • 查看已安装 brew list

  • 检查更新 brew outdated

  • 清理历史版本 brew cleanup / brew clean [software]

  • 管理

    • 查看所有服务 brew services list
    • 单次运行 brew services run [服务名]
    • 运行并设置开机自启 brew services start [服务名]
    • 停止 brew services stop [服务名]
    • 重启 brew services restart [服务名]

  • 卸载软件及依赖包 brew rmtree nginx

    需要安装 rmtree 包
