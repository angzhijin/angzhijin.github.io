Maven命令行小结

发表于2022-07-05|更新于2022-07-05|学习笔记
|字数总计:416|阅读时长:1分钟|阅读量:
  • Maven – Welcome to Apache Maven

#基本命令

  • mvn -v：查看版本
  • mvn -help：查看帮助

用的多的就这俩，其他的看看help吧

#常用命令操作

#创建项目

  • -DgroupId=: 包名
  • -DartifactId=: 项目名称
  • -DarchetypeArtifactId=: 指定ArchetypeId
    • maven-archetype-quickstart: Java项目
    • maven-archetype-webapp: web项目
  • -DinteractiveMode: 是否使用交互模式

#清理

mvn clean

清除/target文件，相当于将编译生成的.class文件全部删除

#编译

mvn compile

将src/main/java下的java源码生成为.class文件到/target目录下

#测试编译

mvn test

将src/test/java下的源码编译

#打包

mvn package

生成压缩文件(jar/war等)到/target目录下

#安装

mvn install

将压缩文件上传到本地仓库

#部署

mvn deploy

将压缩文件上传到私服

#Lifecycle

Maven的编译命令都是围绕lifecycle进行的，这里列了常见的几个，更详细的就参考Maven – Introduction to the Build Lifecycle

#Clean

  • pre-clean: 清理前的准备
  • clean: 清理
  • post-clean

#Default

当执行compile, test, package, install, deploy时, 其前面的生命周期也会自动执行

  • validate: 验证项目正确性
  • initialize
  • generate-sources
  • process-sources
  • generate-resources
  • process-resources
  • compile: 编译源代码
  • process-classes
  • generate-test-sources
  • process-test-sources
  • generate-test-resource
  • process-test-resources
  • test-compile
  • process-test-classes
  • test: 编译测试代码
  • prepare-package
  • package: 打包
  • pre-integration-test
  • integration-test
  • post-integration-test
  • verify: 验证有效
  • install
  • deploy

#Site

  • pre-site
  • site
  • post-site
  • site-deploy

#其他命令

#工程转换

  • mvn idea:idea: 原生maven项目转换为idea项目
  • mvn idea:clean: idea转换为maven原生项目
  • mvn eclipse:eclipse: 原生maven项目转换为eclipse项目
  • mvn eclipse:clean: eclipse转换为maven原生项目
