Redis命令

#键命令

[COMMAND] [KEY_NAME]

  • DEL key：删除
  • DUMP key：序列化
  • EXIST key：是否存在 key
  • TYPE key：key所存储的值的类型
  • RENAME key newkey：修改key
  • RENAMENX key newkey：仅当newkey不存在时才修改key
  • KEYS pattern：匹配key集
  • RANDOMKEY：随机返回一个key
  • SCAN cursor [MATCH pattern] [COUNT count]：迭代数据库中的数据库键
  • MOVE key db：将当前数据库中的key移动到目标db中
  • EXPIRE key seconds：为给定key设置过期时间（秒）
  • EXPIREAT key timestamp：为给定key设置过期时间（UNIX时间戳）
  • PEXPIRE key milliseconds：为给定key设置过期时间（毫秒）
  • PERSIST key ：移除key的过期时间，保持持久
  • PTTL key：返回key的剩余过期时间（毫秒）
  • TTL key：返回key的剩余生存时间（TTL，time to live）

#数据类型

#字符串String

  • SET key value：添加

  • GET key：获取

  • SETNX key value：当key不存在时赋值

  • GETSET key value：修改值，返回旧值

  • STRLEN key：返回key对应字符串的长度

  • APPEND key value：如果key已存在且是一个字符串，将value追加到原值末尾

  • GETRANGE key start end：返回key对应值的子字符串

  • SETRANGE key offset value：用value覆写偏移量offset开始的字符串值

  • GETBIT key offset value：对key存储的字符串，返回偏移量上的位

  • SETBIT key offset value：对key存储的字符串，设置或清除指定偏移量上的位

  • MGET key [key...]：获取多个key的值

  • MSET key1 value [key value ...]：设置一个或多个k-v对

  • MSETNX key1 value11 [key value ...]：设置一个或多个k-v对，当且仅当所有key都不存在

#哈希Hash

redis中的hash是一个string类型的field - value（字段 - 值）对的映射表

  • HSET key field value：将F-V对设置到哈希表key中
  • HSETNX key field value：只有在field不存在时，设置F-V
  • HGET key field：获取哈希表key中field字段的值
  • HGETALL key：获取哈希表key中的所有字段和值
  • HDEL key field [field...]：删除一个或多个哈希表字段
  • HEXIST key field：查看哈希表key中，是否存在指定的字段
  • HLEN key：获取哈希表key中字段的适量
  • HKEYS key：获取哈希表key中所有的字段
  • HVALS key：获取哈希表key中所有字段的值
  • HMSET key field value [field value ...]：同时将多个F-V对设置到哈希表key中
  • HMGET key field [field...]：同时获取哈希表key中多个field的值
  • HSCAN key cursor [MATCH pattern] [COUNT count]：迭代哈希表key中的键值对

#列表List

一个简单的字符串列表，按照插入顺序，可以添加元素到列表的头部（左边）或尾部（右边）

  • LPUSH key value [value...]：将一个或多个值插入到列表key头部
  • LPUSHX key value：将一个值插入到已存在的列表key头部
  • LPOP key：获取列表key的第一个元素并移出
  • LREM key count value：移除列表元素（count>0，前往后移除与value相等的count个元素；count<0，后往前移除与value相等的|count|个元素；count=0，移除所有与value相等的元素）
  • LLEN key：获取列表key的长度
  • LINSERT key before|after pivot value：在列表的元素前、后插入value
  • LINDEX key index：通过索引获取列表key的元素
  • LSET key index value：通过索引设置列表key的元素
  • LRANGE key start end：获取列表key指定范围内的元素
  • LTRIM key start end：修剪列表，保留[start-end]间的元素，其余的删除
  • RPUSH key value [value...]：在列表中添加一个或多个元素
  • RPUSHX key value：在已存在的列表中添加一个或多个元素
  • RPOP key ：获取并移除最后一个元素
  • RPOPLPUSH source destination：移除列表source的最后一个元素，并将元素添加列表destination

#集合Set

String类型的无序集合，集合成员是唯一的。

Redis中的集合时通过哈希表实现的

  • SADD key member [member...]：向集合中添加一个或多个成员
  • SREM key member [member...]：移除集合中的一个或多个成员
  • SISMEMBER key member：判断member是不是集合key的成员
  • SCARD key：获取集合的成员数
  • SMEMBERS key：返回集合中纲得所有成员
  • SPOP key：随机返回并移除一个成员
  • SRANDMEMBER key [count]：获取集合中的一个或多个随机成员
  • SMOVE source destination member：将member元素从集合source移动到集合destination
  • SSCAN key cursor [MATCH patern] [COUNT count]：迭代集合中的成员
  • SINTER key1 [key...]：返回给定集合的交集
  • SINTERSTORE destination key1 [key...]：将给定集合的交集保存到集合destination中
  • SUNION key1 [key...]：返回给定集合的并集
  • SUNIONSTORE destination key1 [key...]：将给定集合的并集保存到集合destination中
  • SDIFF key1 [key...]：返回集合key1和其他集合的差异
  • SDIFFSTORE destination key1 [key...]：将集合key1与其他集合的差异保存到destination中（集合key1中独有的成员）

#有序集合zset(sorted set)

与Set不同的是Zset中每个成员都会关联一个double类型的分数score，redis通过分数来为集合中的成员进行从小到大排序

成员是唯一的，但分数可以重复

  • ZADD key score member [score member...]：向有序集合中添加一个或多个成员，或更新已存在成员的分数
  • ZCARD key：获取集合的成员数
  • ZRANK key member：获取有序集合key中成员member的索引（下标）
  • ZREVRANK key member：获取有序集合key中成员member的排名，有序集合成员按分数值从大到小排序
  • ZSCORE key member：获取有序集合key中成员的分数值
  • ZCOUNT key min max：统计有序集合key中分数在[min,max]间的成员数
  • ZLEXCOUNT key min max：统计有序集合key中在指定字典区间的成员数
  • ZRANGE key start end [WITHSCORES]：获取有序集合指定索引（下标）区间内的成员
  • ZRANGEBYLEX key start end [LIMIT offset count]：获取有序集合key指定字典区间内的成员
  • ZRANGEBYSCORE key min max [WITHSCORES] [LIMIT]：获取有序集合key指定分数区间内的成员
  • ZREM key member [member...]：移除集合key中的一个或多个成员
  • ZREMRANGBYLEX key min max：移除集合key中位于给定字典区间的成员
  • ZREMRANGEBYRANK key start end ：移除集合key中位于给定索引区间的成员
  • ZREMRANKBYSCORE key min max：移除集合中位于给定分数区间的成员
  • ZINCRBY key increment member：有序集合key中对指定成员的分数加上增量increment
  • ZREVRANGE key start end [WITHSCORE]：获取有序集合key中指定索引区间内的成员，分数从高到低
  • ZREVRANGEBYSCORE key start end [WITHSCORE]：获取有序集合key中指定索引区间内的成员，分数从高到低
  • ZSCAN key cursor [MATCH pattern] [COUNT count]：迭代有序集合中的成员，包括成员和分数
  • ZINTERSTROE destination numkeys key [key...]：计算给定的numkeys个有序集合的交集，并存储到有序集合destination中（结果中成员分数为给定集合中该成员的分数之和）
  • ZUNIONSTORE destination numkeys key [key...] ：计算给定的numkeys个有序集合的并集，并存储到有序集合destination中

#事务

先以MULTI开始一个事务，然后将多个命令入队到事务中，最后由EXEC命令触发，一并执行事务中的所有命令。

  • DISCARD：取消事务，放弃执行事务块内的所有命令
