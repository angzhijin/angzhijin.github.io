#Mac+Homebrew

也可下载一键式启动App: Postgres.app，自带PostGIS插件。

直接执行psql会报error: connection to server on socket "/tmp/.s.PGSQL.5432" failed: FATAL: database "系统用户" does not exist

psql postgres进入数据库我们会发现，执行\du发现用户只有一个系统用户（密码也是系统密码），执行\l指令后发现当前数据库的所有者都是系统用户，即不存在postgres用户，但存在默认的postgres数据库，且属于系统用户。

为了修改PG的用户为常用的postgres用户管理，需要进行以下操作

至此，我们Mac上的PG就有两个管理员，一个系统用户（超级用户），一个postgres。

卸载：

brew uninstall postgresql

或安装 brew 的rmtree 将相关的依赖一起删除
