#什么是AOP

AOP，Aspect Oriented Programming，面向切片编程，在面经中不知道遇到了多少次，背的也是迷迷糊糊的，其中一大原因是之前一点没接触到过它的用处。到了工作中，观摩各位大佬的代码，不经意间发现了其中的Aspect的应用，这才开始有所明悟（也发现了自己之前学的有多混）。

在软件业，AOP为Aspect Oriented Programming的缩写，意为：面向切面编程，通过预编译方式和运行期间动态代理实现程序功能的统一维护的一种技术。AOP是OOP的延续，是软件开发中的一个热点，也是Spring框架中的一个重要内容，是函数式编程的一种衍生范型。利用AOP可以对业务逻辑的各个部分进行隔离，从而使得业务逻辑各部分之间的耦合度降低，提高程序的可重用性，同时提高了开发的效率。

切面，按我自己的理解来就是两个模块间的那一部分，在结构上好比关系型数据库中的关系表一样。

切片的作用，就是将一些公共的处理，比如说日志管理、权限控制等功能进行封装，统一管理，减少代码重复度，降低模块间的耦合度。

目前接触到的实现与拦截器类似，在Web请求的响应前后，获取请求的信息，以及响应的数据。

#基本术语

  • 切面Aspect：拦截器类
  • 通知Advice：拦截后要执行的代码，包含前置Before、后置After、围绕Around等不同类型
  • 目标Target：要被增强的对象
  • 代理Proxy
  • 连接点Joinpoint：拦截的某个执行点
  • 切入点Pointcut：具体拦截的某个业务点的定义
  • 增强器Advisor：切面的另一种实现，由切入点和通知组成

#过滤器、拦截器与AOP

这三个在效果上有一定的相似性，但又有其不同的地方

#过滤器

过滤器主要用于对用户请求进行预处理和后处理，有一个典型的处理链。

#完整流程

  1. Filter对用户请求进行预处理
  2. 将请求交给Servlet进行预处理并生成响应
  3. Filter对服务器响应进行后处理

#常见的几个过滤器

  • Authentication Filter 用户访问权限过滤
  • Logging and Auditing Filter 日志过滤
  • Image conversion Filter
  • Data compression Filter
  • Encryption Filter
  • Tokenizing Filter
  • 。。。

#实现方式

实现 javax.Servlet.Filter接口，并重写三个方法：

  1. 初始化void init(FilterConfig config)

  2. 销毁void destroy()，完成某些资源的回收

  3. 过滤功能void doFilter(ServletRequest request, Servletresponse response, FilterChain chain)

    以chain.doFilter(request, response)执行请求响应，区分前后

#注册方式

  1. @Component注解
  2. SpringBoot 中使用Config类(@Configuration)，可以自由配置拦截的URL
  3. SpringMVC 在web.xml中注册

#缺陷

Filter无法知道请求是由哪个Controller执行的

#拦截器

在某个方法或字段被访问之前，进行拦截，然后在之前或之后加入某些操作

是AOP的一种实现策略。

#作用

  • 日志记录
  • 权限检查
  • 性能监控
  • 通用行为

#实现方式

实现HandlerInterceptor接口，并重写三个方法：

  1. boolean preHandler(HttpServletRequest request, HttpServletResponse response, Object handler)

    请求处理前调用（Controller方法前），可以进行一些前置初始化操作，或是对请求的预处理，或判断请求是否继续（return false）

  2. postHandler(HttpServletRequest request, HttpServletResponse response, Object handler, ModelAndView modelAndView)

    请求处理后调用（Controller方法后），会在DispatcherServlet进行视图返回渲染前被调用，可以在值里对Controller处理后的ModelAndView进行操作

  3. afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handle, Exception ex)

    当前对应的preHandler返回值为true时才执行，主要用于进行资源清理。

#注册方式

@Component修饰 + 实现WebMvcConfigurer手动注册

SpringMVC中通过xml文件配置<mvc:interceptors>

#缺点

不能够获取request的参数以及控制器之后的response
