Docker使用

发表于2022-03-04|更新于2022-04-20|工具使用
|字数总计:1.2k|阅读时长:4分钟|阅读量:

Docker是一个开源的应用容器引擎。

可以让开发者打包他们的应用以及依赖包到一个轻量级、可移植的容器中，然后发不到任何流行的Linux机器上，也可以实现虚拟化。

优点：

  • 快速、一致地交付应用程序
  • 响应式部署和扩展
  • 在同一硬件上更多工作负载
概念 解释
镜像image 相当于一个root文件系统
容器Container 容器是镜像运行的实体，容器可以被创建、启动、停止、删除、暂停
仓库Repository 可看作代码控制中心，用于保存镜像

#安装Docker-Compose

Docker-Compose是用于定义和运用多容器Docker应用程序的工具。

通过Compose可以使用yaml文件来配置应用程序所需要的服务，然后使用一个命令，就可以从yaml文件配置中创建并启动所有服务。

Docker-compose是自动化编排容器，基于docker-compose.yml进行配置启动，通常启动的是一个服务，这个服务由好几个container组成。

  • docker version - 查看docker版本

#容器使用

以ubuntu容器为例

  • docker pull ubuntu 拉取 ubuntu镜像

  • docker run -itd --name ubuntu-test ubuntu /bin/bash 使用ubuntu镜像启动一个容器

    • -i：交互式操作
    • -t：终端
    • -d：后台运行
    • --name ubuntu-test：容器命名
    • ubuntu：ubuntu镜像
    • /bin/bash：放在镜像后的是命令，这里是希望有交互式shell
    • 退出终端：直接输入exit
    • 进入容器：docker attach 或 docker exec ..
    • attach进入后再退出，会导致容器停止，一般建议使用exec

  • docker container ls：查看所有容器

  • docker ps ：查看正在运行的容器

    • -a：查看所有容器

  • docker stop <容器 ID>：停止一个容器

  • docker start <容器 ID>：启动一个已停止的容器

  • docker rm -f <容器 ID>：删除容器

    • -f：强制删除还在运行的容器

#镜像使用

  • docker images：列出本地主机上的镜像
  • docker pull <镜像名>：获取一个新的镜像
  • docker search <镜像名>：查找镜像
    • 也可以从Docker Hub网站上搜索
  • docker rmi <镜像名>：删除镜像
  • docker image prune：清理临时的、没有被使用的镜像文件

此外还有创建镜像等其他功能，由于这些功能需求不大，就没去深入了解了
