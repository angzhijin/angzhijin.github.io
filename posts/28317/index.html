一种是从两位数着手，计算两个两位数乘积是否为回文数；

另一种是从乘积着手，两个n位数相乘最大只会是n*n位数，所以从最大的如9999开始往下找回文数使其为两个数相乘（应该是需要找出因数）

从题解处学习了一下，发现还是有规律的。假设两数为10n−a10^n-a10n−a与10n−b10^n-b10n−b，则两数乘积为[10n−(a+b)∗10n]+a⋅b[10^n-(a+b)*10^n]+a·b[10n−(a+b)∗10n]+a⋅b，这里可以看出乘积的前n位为10n−(a+b)10^n-(a+b)10n−(a+b)，后n位为a⋅ba·ba⋅b，若为回文数，则两者应为翻转数。

假设x=a+b,则L=a⋅b=Rev(10n−(a+b))=Rec(10n−x)x=a+b, 则L=a·b=Rev(10^n-(a+b))=Rec(10^n-x)x=a+b,则L=a⋅b=Rev(10n−(a+b))=Rec(10n−x)，可以得到a=−x+x2−4×L2a=\frac{-x+\sqrt{x^2-4\times{L}}}{2}a=2−x+x2−4×L​​，即x为偶数，则从小到大遍历偶数使其满足a的条件即可。

数学计算，需要注意的是幂可能会是负数。

这道题和【29】有着异曲同工之处。也可以采用倍增。

而且还需要注意有几个特殊情况：1. 任何数的0次幂都是1；2. 1的任意次幂是1；3. -1的奇数次幂是-1，偶数次幂是1；4. 幂为Integer.MIN_VALUE时，取反后会溢出，此时的结果可以直接返回0。同时“2，3，4”中“4”优先级最低。

官方题解对幂的拆解做了另一种解释，幂次可以根据二进制中1的位置进行拆解，如77(0x1001101)，那么77=1+4+8+64。这样只要从x开始不断平方，遇到符合的幂次，就可以将对应的计入答案。

【372】超级次方

Link：372. 超级次方 - 力扣（LeetCode）

单纯看题就觉得麻烦，在看了讨论区大佬列了一个测试用例，人麻了，才注意到输入数组的大小范围[1,2000]。

再次看起了三叶姐姐的题解。

次方在推演之后为：ab=(a∣b10∣)10∗a(bmod  10)a^b = (a^{|\frac{b}{10}|})^{10} * a^{(b \mod 10)}ab=(a∣10b​∣)10∗a(bmod10)

这样对于每个幂，都可以将个位数独立出来，然后套用递归。

另外，对于取模的公式变换不是很了解，就去搜了下，

发现取模还有分配律：abmod  n=[(amod  n)(bmod  n)]mod  nab\mod n = [(a\mod n)(b\mod n)]\mod nabmodn=[(amodn)(bmodn)]modn，

那么可以进一步推出：abmod  n=[(amod  n)b]mod  na^b \mod n = [(a\mod n)^b]\mod nabmodn=[(amodn)b]modn

原式就可以推为$ [(a{|\frac{b}{10}|}){10} * a^{(b \mod 10)}]\mod n = [(a{|\frac{b}{10}|}){10}\mod n]*[a^{b \mod 10}\mod n] \mod n$

第一次注意到mod也是有不会少推演公式的，还有：

  1. 恒等式
    • $(a\mod n)\mod n = a \mod n $
    • nxmod  n=0,x>0n^x \mod n = 0,x>0nxmodn=0,x>0
    • abp−1mod  n=amodp,p为质数且不为b的质数ab^{p-1} \mod n = a mod p,p为质数且不为b的质数abp−1modn=amodp,p为质数且不为b的质数
  2. 逆运算
    • [(−amod  n)+(amod  n)]mod  n=0[(-a\mod n)+(a \mod n)]\mod n=0[(−amodn)+(amodn)]modn=0
    • [(b−1mod  n)(bmod  n)]mod  n=1,当且仅当b与n互质[(b^{-1}\mod n)(b\mod n)]\mod n = 1, 当且仅当b与n互质[(b−1modn)(bmodn)]modn=1,当且仅当b与n互质
  3. 分配律
    • (a+b)mod  n=[(amod  n)+(bmod  n)](a+b)\mod n=[(a\mod n)+(b\mod n)](a+b)modn=[(amodn)+(bmodn)]
    • abmod  n=[(amod  n)(bmod  n)]mod  nab \mod n = [(a \mod n)(b \mod n)]\mod nabmodn=[(amodn)(bmodn)]modn
