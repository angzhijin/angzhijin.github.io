Java中定时任务技术

#单机定时任务技术

#Timer

java.util.Timer

内部使用一个叫做TaskQueue的类存放定时任务，是一个基于最小堆实现的优先级队列。

TaskQueue会按照任务距离下一次执行时间的大小将任务排序，保证在堆顶的任务最先执行。

存在缺陷：

  • 一个Timer一个线程，Timer的任务只能串行执行，一个任务执行时间过长会影响其他任务
  • 发生异常时任务直接停止（Timer只捕获了InterruptedException）

#ScheduledExecutorService

ScheduledExecutorService是一个借口，有多个实现类，比较常用的是ScheduledThreadPoolExecutor，支持多线程执行个定时任务并且功能更强大，是Timer的替代品

ScheduledThreadPoolExecutor本身就是一个线程池，支持任务并罚执行。并且，其内部使用DelayQueue作为任务队列。

不论是使用Timer还是ScheduledExecutorService都无法使用Cron表达式指定任务执行过的具体时间。

#SpringTask

  • 5分钟搞懂如何在Spring Boot中Schedule Tasks

使用Spring的@Scheduled注解即可定义定时任务。

Cron表达式主要用于定时作业（定时任务）系统定义执行时间或执行频率的表达式。

  • 在线Cron表达式生成器

但Spring自带的定时调度只支持单机，并且提供的功能比较单一。

底层是基于JDK的ScheduledThreadPoolExecutor来实现的。

#时间轮

简单来说就是一个环形的队列（底层一般机遇数组实现），队列中的每一个元素（时间格）都可以存放一个定时任务列表。

每个时间格代表了时间轮的基本时间跨度/时间精度，根据定时时间放在对应的时间格中。对于超出时间轮大小的定时任务，可以引入圈数/轮数的概念。

还可以采用多层次时间轮，如手表中时针、分针、秒针采用不同的刻度。

时间轮适合任务数量比较多的定时任务场景，它的任务写入和执行的时间复杂度都是O(1)

#分布式定时任务技术

一个定时任务的执行往往涉及：

  • 任务：具体的业务逻辑
  • 调度器：任务管理
  • 执行器：接收调度器分派的任务并执行

#Quartz

完全由Java写的开源任务调度框架

  • 优点

    • 可以很方便的与Spring集成，并且支持动态添加任务和集群

  • 缺点

    • 没有内置的UI管理控制台（可以使用zhaopeiym/quartzui开源项目）

    • 分布式支持不友好

    • API繁琐

#Elastic-Job

GitHub：Java定时任务大揭秘 | JavaGuide

官网：ElasticJob - Distributed scheduled job solution

当当网开源的基于Quartz和ZooKeeper的分布式调度解决方案。

由两个相互独立的子项目Elastic-Job-Lite和Elastic-Job-Cloud组成，使用Lite就好。

Elastic-Job支持任务再分布式场景下的分片和高可用、任务可视化管理等功能

Elastic-Job中的定时调度都是由执行器自行触发（去中心化设计）。

  • 优点：可以与Spring集成、支持分布式、支持集群、性能不错

  • 缺点：依赖额外的中间件如Zookeeper（复杂度增加，可靠性降低，维护成本变高）

#XXL-JOB

GitHub：xuxueli/xxl-job

官网：分布式任务调度平台XXL-JOB

XXL-JOB由调度中心和执行器两大部分组成。（中心化设计）

调度中心负责任务管理、执行器管理以及日志管理。（进行任务调度时通过自研RPC实现）

执行器主要接收调度信号并处理

  • 优点：开箱即用，与Spring集成，支持分布式，支持集群，内置UI管理控制台
  • 缺点：不支持董涛添加任务

#PowerJob

膜拜一下大佬的项目历程：我和我的任务调度中间件_哔哩哔哩_bilibili

GitHub：PowerJob/PowerJob

官网：PowerJob

  1. 任务调度

    原生提供CRON、固定频率、固定延迟三种常见调度策略

    调度称采用无锁化设计，基于时间轮进行调度

  2. 工作流

    利用DAG（有向无环图）解决任务间复杂依赖问题

    支持上游任务结果传递

    前端可视化绘图&结果展示

  3. 分布式计算

    MapReduce模型：分而治之

  4. 动态容器

    允许开发者开发独立于worker项目之外的Java处理器：以Maven工程项目的维度去阻止一对Java文件

    可维护性+灵活性

  5. 实时日志&在线运维

#系统组件

  • powerjob-server：调度中心，整个公司内部统一部署，负责任务管理和调度
  • powerjob-worker：执行器，提供单机执行、广播执行、分布式计算等功能
  • powerjob-client：可选组件，OpenAPI客户端
