#窗口功能

由于主讲老师就是HHDBCS的开发人员，所以主要还是推荐使用HHDBCS啦。

下面就是分析其他软件的缺点咯

PgAdmin缺点：

  1. 脚本编辑没有自动补全
  2. 没有批量删除表
  3. 格式化效果较差
  4. 需要配合PG才能进行命令行操作，且界面操作性
  5. 不支持多窗口

#Oracle迁移到PolarDB/PG

#数据迁移

数据对应（部分）

数据库 类型 占用/说明
Oracle integer 22 bytes
PG integer 4 bytes
Oracle long 2G bytes
PG long 4 bytes
Oracle number 性能非常高，算法和PG的numeric不一样
PG numeric 为了兼容而设计，性能非常低

工具 - SQL转换

HHDBCS转换方式：

  1. 读取原始数据库，以insert文件格式导出（insert语句模板需要修改表名）
  2. 把文件插入到PolarDB/PG数据库（任务管理中添加sql文件）

注意：

  • 结构、数据分开迁移：注意数据结构可能不同，需SQL转换
  • 添加目标表的名称
  • 可以根据模板调整到理想的插入语句

#应用SQL语句迁移

简单语法差异

名称 Oracle PolarDB/PG
delete delete [from] tab delete from tab
daul select 1*4 from dual select 1*4
select select name from (select * from person) select name from (select * from person) tab
update update person p set p.name = ‘张三’ update person set name= ‘张三’

Oracle独有语法

Oracle PG
start … connect by with 替代
merge with 结合 insert
insert all 多个insert
+ 连接 join
