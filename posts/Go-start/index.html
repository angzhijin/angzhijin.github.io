#特点

Go语言保证了既能达到静态编译语言的安全和性能，又达到了动态语言开发维护的效率，可以用一个表达式来形容Go：Go = C + Python

  1. 继承C语言的一些理念，如表达式语法、控制结构、基础数据类型、调用参数传值、指针等
  2. 引入包的概念，用于组织程序结构
  3. 垃圾回收机制，内存自动回收，不需要开发人员管理
  4. 天然并发
    1. 从语言层面支持并发，实现简单
    2. go routime，轻量级线程，可实现大并发处理，高效利用多核
    3. 基于CPS并发模型（Communicating Sequential Process）实现
  5. 吸收了管道通信模型，形成Go语言特有的管道channel。通过channel，可以实现不用的go route之间的相互通信
  6. 函数可以返回多个值
  7. 新的创新
    1. 如切片slice，延时执行defer

#HelloWorld

  1. 新建项目文件夹/hello

  2. 进入文件夹执行go mod init hello

    没有这一步会导致go: go.mod file not found in current directory or any parent directory; see 'go help modules'问题。但似乎不影响运行

  3. 编写HelloWorld.go

  4. 运行go run HelloWorld.go

  5. 通过go build HelloGo.go 编译输出.exe等可执行文件（视平台有所不同）

  6. 使用gofmt -w hello.go格式化并写入文件

生产环境建议/注意先编译

#格式化字符串

使用fmt.Sprintf(格式化样式, 参数列表)格式化字符串并赋值给新串

  • 格式化样式：字符串形式，格式化符号以%开头
  • 参数列表：多个参数以逗号分隔
格式 描述
%s 字符串。
如：%6s格式化为长度为6的字符串，首部用' '填充
%-6s格式化为长度为6的字符串，尾部用' '填充
%c 字符，数字对应的Unicode字符
%v 按值的本来值输出
%+v 在 %v 的基础上，对结构体字段名和值进行展开
%#v 输出 Go语言语法格式的值
%T 输出 Go语言语法格式的类型和值
%% 输出 % 本体
%b / %o / %d / %x / %X 整型以二/八/十/十六进制/十六加大写字母方式显示
%U Unicode字符
%f 浮点数。如%6.2f表示格式化为长度为6，显示两位小数的浮点数
%p 指针，十六进制方式显示

#数值型

在保证程序正确运行下，尽量使用占用空间小的数据类型

  • 整型

    默认声明为 int/int64

    • unit8 / uint16 / uint32 / uint64：无符号8/16/32/64位整型（1/2/4/8字节）（0 ~ 2^i-1）
    • int8 / int16 / int32 / int64：有符号8/16/32/64位整型（1/2/4/8字节）（-2^(i-1) ~ 2^(i-1)-1）

  • 浮点型

    • float32 / float64：32/64位浮点数（单/双精度）

      默认声明为float64

      一般情况下，float64比float32更精确，开发中推荐使用float64

    • complex32 / complex64：32/64位实数和虚数

  • 其他

    • byte：类似uint8
    • rune：类似int32
    • uint：32或64位（看系统）
    • int：与uint一样大小
    • uintptr：无符号整型，用于存放一个指针

#swich

  1. case从上到下顺序执行，直到匹配成功为止
  2. Go只运行对应的case。（自动提供case后面所需的break）
  3. 可以使用fallthrough（穿透）强制执行后面的case语句，不论下一个case是否满足，默认穿一层
  4. case无需为常数，且取值不必为整数
  5. case表达式的值的数据类型必须与switch的表达式数据类型一样，且不能重复
  6. switch后不带表达式同switch true一样，可以使一长串的if...then...else更清晰

#defer

defer语句会讲函数推迟到外层函数返回之后执行。

推迟调用的函数其参数会立即求值，但直到外层函数返回前该函数都不会被调用

推迟的函数会被压入一个栈中。当外层被调用时，按照后进先出的顺序调用

#派生类型详解

#Pointer 指针

指针保存值的内存地址

类型 *T 是指向T类型值的指针，默认值为nil

& 会生成一个指向其操作数的指针

#struct 结构体

  1. 一个结构体（struct）就是一组字段（field）
  2. 结构体字段使用 . 来访问
  3. 结构体字段也可以使用结构体指针来访问
  4. 使用Name:可以仅对部分字段初始化（与字段名顺序无关）

#数组

类型 [n]T 表示拥有n个T类型值的数组

数组的长度是其类型的一部分，所以数组不能改变大小

#slice 切片

  1. 类型[]T表示一个元素类型为T的切片

  2. 使用a[low : high] 来获取下标位于[low, high)范围内的元素切片

  3. 切片就像数组的引用，修改切片会修改底层数组对应的元素，共享底层数组的切片会观测到这些修改

  4. 切片文法类似于没有长度的数组文法

    []bool{true, true, false}等同于先创建[3]bool{true, true, false}数组，然后构建一个引用了它的切片

  5. 切片拥有长度和容量

    1. 长度就是所包含的元素个数
    2. 容量就是从底层开始数，到其底层元素末尾的个数
    3. 可以通过表达式len(s)和cap(s)来获取

  6. 切片的默认值是nil，长度容量为0，且没有底层数组

  7. 使用make创建切片（创建动态数组）

    1. make函数会分配一个元素为零值的数组并返回一个应用了它的切片

  8. 切片可包含任何类型，甚至包括它的切片

  9. 追加元素

    1. append(s []T, vs ...T) []T
    2. 第一个常数是一个元素类型为T的切片，其余类型为T的值会追加到切片末尾
    3. 结果是一个包含元切片的所有元素加上新添加元素的切片
    4. 当s的底层数组太小，不足以容纳所有给定的值，会分配一个更大的数组，返回的切片会指向这个新分配的数组

  10. 使用for循环的range形式可以遍历数组、切片或映射

    1. 每次迭代返回两个值分别为index和value
    2. 可将下标或值设为_来忽略它，只需要索引可以忽略第二个变量

#map 映射

映射将键值映射到值

  1. 默认值（零值）为nil。即没有键，也不能添加值
  2. make函数会返回给定类型的映射，并将其初始化备用
  3. 映射的文法与结构体类似，不过必须有键名
  4. 若顶级类型只是一个类型名，可以在语法元素中省略

  1. 修改映射

    1. 插入或修改 m[key] = elem
    2. 获取元素 elem = m[key]
    3. 删除元素 delete(m, key)
    4. 通过双赋值检测某个键是否存在 elem, ok = m[key]
      1. 若key在映射中，ok为true，若不在则为false
      2. 若key不在映射中，elem为零值

#函数值

可以用作函数的参数或返回值

Go函数可以是一个闭包。闭包是一个函数值，引用了其函数体之外的变量，该函数可以访问并赋予其引用的变量的值。
