星露谷物语模组

发表于2024-01-21更新于2026-07-18阅读次数

#MOD加载器

要在星露谷中添加模组，需要安装模组加器SMAPI。

  • 模组:使用指南/入门 - Stardew Valley Wiki

#Windows

#安装

  1. 运行依次游戏一次完成初始化；
  2. 下载最新版本的SMAPI；
  3. 解压zip文件（非游戏文件夹内，非括号路径文件夹）；
  4. 双击insatll on Windows.bat进行安装；
  5. 完成安装，根据游戏平台进行启动项配置（如不需要同步Steam或GOG的游戏时长或成就，可以直接启动安装路径下的StardewModdingAPI.exe）：
  • Steam
    1. 不关闭SMAPI安装窗口（关闭了重新运行安装程序就可以）；
    2. 在安装窗口中复制路径文本"...." %common%部分；
    3. Steam中打开Stardew Valley的属性（或导入本地程序命名为Stardew Valley Moded作为区分）；
    4. 修改通用 - 启动选项内容为复制的文本，一般为"C:\Program Files (x86)\Steam\steamapps\common\Stardew Valley\StardewModdingAPI.exe" %command%；
    5. 关闭窗口保存；
    6. 可通过该客户端进行启动。

#更新

下载最新版本，运行安装时会覆盖安装。需要重新配置游戏平台启动项。

#卸载

  1. 重新运行暗转该程序，选择Uninstall SMAPI；
  2. 清除游戏平台的启动项。

#Mac

#安装

  1. 安装 .NET 5（参见图文指南)。
  2. 下载最新版本的SMAPI（参见图文指南）。
  3. 将下载获得的压缩包文件解压到任意位置（不要解压到你的游戏文件夹中）
  4. 双击打开 install on Mac.command, 然后跟随介绍。

启动即可，无需配置steam等配置（只适用于windows）

#更新

直接运行新版的安装程序

#卸载

运行安装程序，选择uninstall选项

#MOD下载

  • 使用最多的是Nexus Mods平台，可注册免费帐户，可直接下载或使用平台的Vortex客户端进行管理
  • ModDrop，使用该网站的ModDrop客户端进行mod管理。
  1. 注意检查是否适配最新版本的游戏，以及SMAPI的Mod兼容性
  2. SMAPI会自动禁用不兼容的Mod

#MOD加载

  1. 找到游戏的安装路径。

    平台 路径
    Steam（Windows） Steam安装路径\steamapps\common\Stardew Valley
    Steam（mac） ~/Library/Application Support/Steam/SteamApps/common/Stardew Valley/Contents/MacOS

  2. 将Mod压缩包解压到安装路径下的/Mods文件夹中，可根据类型分不同的子文件夹区分，SMAPI会扫描/Mods下的所有文件。

  3. 禁用Mod可以在文件夹名字前加.。

#MOD集合

模组基本路径：https://www.nexusmods.com/stardewvalley/mods/{id}

{id}替换为对应的mod id

#SMAPI - Stardew Modding API

id：2400

星露谷模组的核心，必备

#StardewHack

id：3213

星露谷某些模组所需的库，一般为需要修改源代码的模组，如”Wear More Rings“等。

Required Mods
Generic Mod Config Menu（可选）
SMAPI - Stardew Modding API

#Generic Mod Config Menu

id：5098

添加游戏内mod控制面板

Required Mods
SMAPI - Stardew Modding API

#Content Patcher

id：1915

可直接模组内修改游戏的静态文件，如肖像、地图等，而不需要修改xnb文件。

Required Mods
SMAPI - Stardew Modding API

#Stardew Valley Expanded

id：3753

扩展了原有内容，包括27个NPC、50个位置、260个事件、27条鱼等等。大大增加了可玩性。

建议在熟悉原星露谷后再上手该模组。

Required Mods
Content Patcher
Custom NPC Exclusions
Expanded Preconditions Utility
Extra Map Layers
Farm Type Manager (FTM)
Json Assets
SAAT - Audio API and Toolkit
Shop Tile Framework
SMAPI - Stardew Modding API
SpaceCore

#stardewvalley anime mods

id：1839

部分村民的肖像美化（）

注意提供了两个版本，一个是Oho Davi Portrait xnb 1.5，直接替换 ...Stardew Valley/Content/Portraits下的xnb文件；另一个是Portrait Anime Mods OhoDavi 1.5，直接按照正常的mod加载方式。

#Ichi88’s Cute Villagers

id：4918

部分村民的肖像和模型（小矮人，伊芙琳，贾斯，克罗布斯/小黑，莱纳斯，帕姆，桑迪，文森特、巫师）

Required Mods
Content Patcher

#NPCMapLocations

id：239

找人利器啊，绿帽村村民太能瞎逛了，这模组能直接把村民头像显示在地图上。

#TractorMod

id：1401

拖拉机模组，懒人福音，最夸张的配置就是一键清全图了。

感觉配置太过了影响游戏体验，配了3*3的格子，顺便当马骑了

#Simple Foliage

id：8164

提供更多树木的模型

Required Mods
Content Patcher
SMAPI - Stardew Modding API

#Wear More Rings

id：3214

修改角色可佩戴的结束数量，默认6个，最大是8个，原配置是2个。

Required Mods
Generic Mod Config Menu（可选）
SMAPI - Stardew Modding API
StardewHack

#Better Ranching

id：859

宠物、动物可以抚摸、挤奶、剪毛的气泡提示

Required Mods
SMAPI

#Ui Info Suite

id：1150

优化状态UI信息，如;

  • 幸运值图标
  • 经验点数
  • 动物抚摸图标（气泡）
  • 鼠标悬停显示作物种类和收获日期
  • 洒水器、稻草人等作用范围
  • 随时查看日历和任务牌
Required Mods
SMAPI
