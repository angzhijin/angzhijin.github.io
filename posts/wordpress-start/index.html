#文件上传

自定义主题上传时候，然后发现了第一个坑，nginx默认的上传文件大小为1MB，而Sakurario大小有4M+，会报413 Request Entity Too Large错误。需要在nginx.conf中添加配置并重启。

很快啊，第二个坑，php也有默认的文件大小上限，提示上传的文件大小超过php.ini文件中定义的upload_max_filesize值，这个就很明确了，再去改一改然后重启就好了。

得，第三个，报了无法创建目录 wp-content/uploads/2023/05。它的父目录是否可以被服务器写入？，文件权限问题了。

做了几个修改，但实际是哪几个生效也不得而知：

  1. 手动在wp-content目录下添加uploads文件夹，并修改读写权限chmod 777 uploads；
  2. 在wordpress的数据库中，表wp_options中的upload_path修改为wp-content/uploads（原来为空）；
  3. 修改nginx.conf和php.ini中的user和group改为相同的，我是设为了我的ubuntu用户。

#安全

  • 限制登录Limit Login Attempts Reloads

Limit Login Attempts Reloads是其中一款，免费版本提供了登录次数限制以及失败锁定两个功能，像我这种小网站简单用用就行了。

真的服了，装了以后么发现基本每天都有上百次的失败登录，怎么有这么多人这么闲的啊（和苍蝇一样）。试的用户名还是我的二级域名，嘿嘿，太天真了。不过以防万一又把密码设复杂点了。

想起了之前建的青龙面板，也隔三差五有人试着登录然后失败，更何况我这个作为域名主站的平台。。。u1s1，有后台的这点就很恶心，静态网站就没这个烦恼了，但弄不好也有可能被注入。

  • All-In-One Security (AIOS) – Security and Firewall

后面感觉功能有点单一，而且有时候也不会通知，所以又看了看其他的，发现一个All-In-One Security (AIOS)，功能就多了很多，除了登陆限制外，还会对账户、文件等各方面进行检测与修改意见。

  1. 登陆限制：User Login -> Login lockout

    可以配置最大登陆尝试次数、重试时间、最小锁定时间与最大锁定时间。相比Limit Login Attempts Reloads，缺少了登陆失败的线型统计图。

  2. 用户注册

  3. 数据库安全

  4. 文件系统安全

  5. 黑名单管理器

  6. 防火墙

  7. 暴力破解（防苍蝇必备！可以修改登录主页的slug、添加登陆验证码等等。）

#邮件通知

当初和好兄弟一起入坑博客的时候就注意到了，他的wordepress一收到评论马上就有邮件通知，而我的hexo还得依赖第三方网站来实现，比如github的gitalk，valine等等。gitalk能够通过邮件通知，但本身必须登录github账号才可以评论，而在国内登录github对大中来说速度可想而知；valine和waline速度是快了，但没有邮件通知；其他的比如畅言云评给我的广告风有难以接受。这些个评论都各有优缺吧，没一个能够达到wordpres是的效果。

现在自己建了wordpress，那就必须得试试了。

在控制台的“设置 - 讨论”中就有“发邮件通知我”一项，但开启了并没有效果。

搜了搜，貌似是要加插件：WP Mail SMTP，个人使用可以自己决定花（捐赠）多少钱，穷学生只能0元了。

安装好，按照流程配置了SMTP邮箱服务器、账户、SMTP密码等等（刚开始用的163邮箱）。试了一手，结果评论还是不给发邮件，但是修改邮箱地址的通知又能够正常发送，？？？，迷茫

因为涉及邮箱，又在自己的多个邮箱（163，qq）里清了一波垃圾邮件，想了想163还是拿来做办公啊之类的，个人的还是用qq好了。所以就把插件里的发送方邮箱配成了qq邮箱，结果，评论之后就有邮件通知了？？！！163是什么垃圾！
