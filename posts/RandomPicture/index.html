随机图片API

发表于2022-03-06更新于2026-07-18阅读次数

Hexo作为静态博客，在配置文章封面一般都是在Font-matter中指定cover，但为了指定封面每写一篇都要去配置，而自己去配置又想找个内容相关的，而且还想上传到自己图床中（个人强迫症），太难受了。

而在ButterFly主题中，提供了默认封面的配置，可以在其中配置一堆图片URL。在博客生成时，会给对于未提供cover的文章从一堆URL中随机一个作为文章的封面。

刚开始还是老老实实的配置了几张图片进去，后来忽然意识到，如果这些URL返回的是随机图片，那是不是就相当省力了？

初次尝试发现，配置了之后就是相当于html里把图片url修改为随机图片API。这就导致如果文章随机到的URL相同，那么它们的封面也就是相同的；而且每次刷新，都会发起新的请求，图片被更新，即每篇文章的封面都不会固定了。唯一的缺点是永远不知道会随机出什么奇奇怪怪的图片。

既然是随机配置，那么我就多配置一些，我设定的主页一页也就显示10篇文章，除去一些自己配置的封面，那么我只要配置10+个的URL不就不容易重复了？

所以我捣鼓了半天，根据沐云湘夕大大整理的随机壁纸API，简单搭了个Hexo-ButterFly本地博客用于测试各个随机API在应用到封面上的效果（已排除部分国外源以及需要申请Token的网站）

#博天API

说明文档：随机壁纸-搏天api (btstu.cn)

除了随机图片，博天还有提供其他的API

  • 请求方式：GET

  • 请求地址：https://api.btstu.cn/sjbz/api.php

  • 请求参数

    名称 必填 类型 说明
    method 否 string 图片平台类型【moblie / pc / zsy】默认pc
    lx 否 string 图片分类【meizi / dongman / fengjing / suiji】默认随机
    format 否 string 输出格式【json / images】默认images

  • 返回参数(json)

    名称 类型 说明
    code string 返回的状态码
    imgurl string 图片地址
    width string 图片宽度
    height string 图片高度

#保罗API

说明文档：随机动漫壁纸 - 保罗｜API (paugram.com)

随机频率较低，且图片均为人物，且左半边空白

  1. 动漫壁纸

    • 调用地址：https://api.paugram.com/wallpaper/

    • 参数

      参数 可选值 描述
      source 【sm / cp / sina / paul】 图片源
      category 【cn / us / jp】 图片分类，可按国家和类别选择（开发中）

    • 图片源

      • sm：SM.M S图床
      • gt：GiteePage 托管
      • sina：新浪图床
      • github：GitHub图床，基于 JSDelivr cdn

  2. Bing每日壁纸

    • 调用地址：https://api.paugram.com/bing/
    • 参数：info，添加后返回json格式

另外还有Gravatar头像解析、随机动漫音乐API，网易云解析

#东方 Project

说明文档：Paulzzh – 东方Project随机图片API

收录45000+张东方高质量壁纸图片，牛皮

  • 调用地址：https://img.paulzzh.com/touhou/random

  • 参数（均为可选）

    字段 描述
    type 302 (默认)
    json 支持跨域
    site konachan 仅使用konachan(此方酱)(默认)
    yandere 仅使用yande.re(病娇酱)——（已不支持）
    all 全部使用
    size pc 横屏壁纸(默认)
    wap 竖屏壁纸
    all 全部
    proxy 1 使用反向代理 (默认)
    0 302返回源站链接
    tag 无默认值
    筛选指定标签的图片，可能较慢(beta)
    例如：博丽灵梦(reimu) 蓬莱山辉夜(kaguya)
    琪露诺(cirno) 短发(short_hair)
    红眼(red_eyes) 夜晚(night)
    更多标签详见https://img.paulzzh.com/touhou/random_tags（该链接已失效）
