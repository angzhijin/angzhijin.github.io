平台使用

LeetCode

  • 官网主页：力扣（LeetCode）官网 - 全球极客挚爱的技术成长平台
  • 个人主页：angzhijin - 力扣（LeetCode） (leetcode-cn.com)

IDEA

目前主用JAVA，所以使用IDEA较多，其插件库中也提供了LeetCode插件

LeetCode插件

  1. 在IDEA的 Preferences - Plugin 中搜索 LeetCode Editor，并安装

  2. 在 Preferences - Tools - LeetCode Plugin 中配置

    • 账户信息，包括使用的LeetCode官网（中/外）、使用的编程语言、账户及密码

    • 本地项目路径

      建议直接定位到项目的/src目录下，配合自定义模板在添加题目时可直接生成main用于测试

    • 代码模板

      使用自定义模板需勾选 Custom Template

      为了便于按题号搜索，我在类名后添加了题目编号

      • CodeFileName：代码文件名

      • CodeFileName：每道题的初始化模板

      • TempleConstant：题目信息常量获取

    1. 使用

      1. 侧边栏打开插件面板
      2. 登陆
      3. 双击题目生成代码模板
      4. 开始刷题

VSCode

  1. 插件中搜索LeetCode并下载（第一个下载量最多的就是）
  2. 在侧边栏打开LeetCode面板
  3. 点击小地球切换到力扣
  4. 登陆Sign in to LeetCode, 之后点击LeetCode Account
  5. 选中题目后会出现题目，右下角选择Code Now，选择自己的语言开始刷题
  6. 第一次做题会问你本地路径建在哪
