Canal初探

发表于2022-08-19更新于2026-07-09

Canal，主要用途是基于 MySQL 数据库增量日志解析，提供增量数据订阅和消费

基于日志增量订阅和消费的业务包括

  • 数据库镜像
  • 数据库实时备份
  • 索引构建和实时维护(拆分异构索引、倒排索引等)
  • 业务 cache 刷新
  • 带业务逻辑的增量数据处理

GitHub： alibaba/canal: 阿里巴巴 MySQL binlog 增量订阅&消费组件

QuickStart：QuickStart · alibaba/canal Wiki

#安装

#准备

  1. 自建的MySQL，需要开启binlog功能，mysql配置

  2. 重启mysql

  3. 查看是否启动binlog

  4. 创建用户并授权（已有canal角色就直接）

#启动

  1. 下载

    • release

  2. 解压

    解压完成后在/tmp/canal下存在5个目录bin, conf, lib, logs, plugins

  3. 配置

  4. 启动

  5. 查看server日志

  6. 查看instance日志

  7. 关闭

#Q&A

  1. 运行sh bin/startup.sh 时提示found canal.pid , Please run stop.sh first ,then startup.sh，运行sh bin/stop.sh后又提示[: unexpected operator导致无法关闭

    由于shell环境不兼容导致，使用bash bin/stop.sh进行关闭

  2. 启动后没有QuickStart说的log文件，只有canal_stdout.log，且其中内容为...'Cannot allocate memory'...

    内存不够，jvm无法启动

    在/bin/startup.sh中的JVM参数-server -Xms2g -Xmx3g -XX:+UseG1GC -XX:MaxGCPauseMillis=250 -XX:+UseGCOverheadLimit -XX:+ExplicitGCInvokesConcurrent。

    比较尴尬的是由于rocketMQ的启动，导致留给canal的内存不够用。。。
