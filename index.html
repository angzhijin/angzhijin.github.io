Hexo博客搭建

简单介绍

建好这个Blog也已经有了快两个月的时间了，我把自己建立博客的过程整理了一下

环境建立

Hexo+个人服务器的配置模式相当于在本地（以下通过PC代表本地）上生成一个博客项目，通过git将其同步到服务器中。

本地Hexo环境

具体安装过程就略过了

  1. 安装node.js

  2. 安装Git

  3. 安装Hexo

    最终的一个Hexo项目就位于D:\MyBlog\hexoBlog下。文件夹内容说明如下：

    • node_modules: node依赖包
    • scaffolds: 生成文章的一些模板
    • source: 用来存放文章
    • themes: 存放主题文件
    • _config.yml: 配置文件（配置参考 | Hexo)
      • title：网站标题
      • subtitle：网站副标题
      • description：网站描述
      • author：名字
      • language：语言
      • timezone：网站时区

服务器准备

  1. 购买服务器（我的是腾讯云轻量级应用服务器）

  2. 域名注册

  3. 域名实名认证

  4. 服务器备案

    备案需要有服务器和域名

Git

  2. 创建git用户

  3. 给git用户配置ssh免密公钥登录

  4. 配置git仓库

评论

因为是在国内，所以优先尝试了畅言云评 。它的评论界面简约而且是粉色系，还挺好看的，但由于其评论需要登陆微信等第三方账号，同时在左侧边栏带了用户的个人中心，比较难接受，选择Pass。

后面尝试使用Gitalk，是基于GitHub的OAuth应用以及个人仓库的Issue项对评论进行管理，唯一不好的是只支持GitHub账号登陆，在国内GitHub毕竟网络不佳。

下面是Gitalk的配置。

  1. 创建一个GitHub仓库Hexo-comment（名字随意），其Issue将作为评论管理区。

  2. 创建OAuth应用（New OAuth Application），记下以下信息

  3. 添加icarus配置
